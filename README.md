# Airline Reservation System

## Team Members
- Kuhlekonke Phungula
- Uwaiz Lovell

## Description
A console-based airline reservation system that simulates the operations of an airline booking platform; featuring real seat-map visualization, passengers, bookings, cancellations, automatic waitlists, and a revenue report. 

## How to run
python airline.py

## Features
1. Add a flight
2. Register a passenger
3. View seat map
4. Book a seat
5. Cancel a booking
6. Change a seat
7. Flight manifest
8. Revenue report
9. Exit
